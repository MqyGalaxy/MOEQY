# 萌趣 MOEQY 4.0

使用 Astro 5 重构的个人主页。旧站来自 `D:/WEBsite/Blog3.0/home3.0/MOEQY`，参考设计来自上级 `参考` 目录保存的「わたなれ」官网。全部开发文件和素材独立保存在本目录；构建不依赖旧站目录。

## 本地运行

推荐 Node.js 22 或 24。依赖与 `package-lock.json` 已安装、生成。

```powershell
cd D:\WEBsite\Blog3.0\home4.0\MOEQY
npm ci
npm run dev
```

浏览器访问终端显示的地址，默认是 `http://localhost:4321/`。如果在受限环境里 Astro 的遥测配置目录不能写入，可以先执行 `$env:ASTRO_TELEMETRY_DISABLED='1'`。

```powershell
npm run check
npm run build
npm run verify
npm test
npm run preview
```

`dist/` 是可部署的完整静态网站，可用于 GitHub Pages、Cloudflare Pages 或其他静态托管服务。构建命令为 `npm run build`，输出目录为 `dist`。原有 `CNAME` 已保留。网站没有在本次重构中发布。

## 设计

首页以全屏 PICK UP 开场，随后是 INTRODUCTION（含兴趣切换）、NEWS、WORKS、博客与关于／FAQ 入口。角色 Hero 与滚动文字带位于 About，滚动入口指向该页正文。中英文使用共享组件，首页 `#about` 与旧分页地址继续有效。

`PickupHero.astro` 共用中英文活动文案。桌面保留视频分割线，信息区以浅粉 `#fdeef5` 网点底板衔接，叠加淡粉圆形、蓝绿色圆片、错位粉色纸条和小型心形／三角。底板铺到页面边缘，正文处降低纹理对比，不使用卡片边框或阴影。右侧宽度为 `min(48cqw, 880px)`，标题 32–56px、正文 16–18px，右边缘仍沿用统一页边距；文字区顶部根据视频曲线计算安全距离。

左下方 PICK UP 使用实心主字、错位描边与粉蓝色块，编号和辅助文字随组合一起对齐。`site.ts` 与 SVG 共用控制点：桌面主字限制在曲线左侧水平区内，组合距可见底边 16px；手机和平板按装饰覆盖范围内的最高边界留出 12px，避开文件夹肩部。窗口变化、字体加载后复算，滚动不会改变装饰在视频内的位置。不要恢复百分比底部留白或单独修改一套曲线检测值。

手机和平板使用单屏视频加两行原文布局：390×844 下视频高度约 557px（66%），底部信息区约 287px。手机页签分界保持 40px 高度差、72px 过渡宽度；平板为 48px 与 88px，两侧水平，圆角短斜边不会随视频高度变成长缓坡。浅粉信息区仅保留一组小型圆片／纸条，装饰不增加内容高度。所有尺寸的通知均置于视频内、页头下方，随首屏滚出，避开底部装饰与按钮。

所有断点的 Hero 均固定为 `100svh`，长文案或缩放不会撑高首屏。桌面操作区底边与视频最低水平段对齐，底部间隔与 SVG 共用控制点。正文始终来自原文：桌面最多四行，手机／平板最多两行，超出部分省略显示。`data-copy-mode` 仅在空间不足时收紧编号、标题和操作区，空间恢复后还原布局，不切换到另写的简介。标题最多两行，极小空间一行；完整标题、正文及详情链接仍在介绍弹层中。无 JavaScript 时阅读入口直接访问原活动详情页。

`src/data/zh-CN.yml` 与 `src/data/en.yml` 的 `index.text` 是首屏和弹层的同一份正文；已移除独立的 `index.summary`。桌面句尾使用项目图标库 `icon-window-down`，无底色；短正文后自然跟随，超长正文在第四行右侧预留图标空间。手机保留“活动介绍 / Read more”。两个入口均打开同一个原生弹层，支持按钮、Escape、遮罩关闭，并向实际触发入口恢复焦点；无 JavaScript 或不支持 dialog 时进入原活动详情地址。历史日期和文章正文不变。减少动态效果时显示静态封面并取消装饰动画，视频弹窗关闭后卸载播放器。

全站页头固定，避开桌面右侧导航。首页 Logo 位于视频内时使用现有白色版本，页头背景透明；经过实际视频曲线时交叉淡化为原色 Logo，并从透明淡入白色底衬；继续滚动约 160px 后，Logo 缩小，白色底衬保持显示；向上回到视频区域时，底衬才重新淡出至透明。Logo 始终显示，手机菜单仍为 48px。内页从原色 Logo 开始，滚动后同样收紧。SVG 裁切与页头边界检测共用贝塞尔控制点；`header.css` 管理尺寸和过渡，`site.ts` 合并滚动、缩放、字体与页面恢复更新，锚点留出固定页头空间。

沿用参考站的粉色 `#e65097`、蓝色 `#45b9c8`、紫灰色 `#785978`，结合点阵、倾斜文字带、超大英文标题、固定侧边导航、角色主视觉与留白。角色、标识、作品封面和视频使用旧站自己的素材，没有引入参考作品的人物或宣传内容。

首页 NEWS 展示最新三篇图文卡片：桌面三列，平板与手机可横向滚动并吸附定位；归档保留原来的列表和分页。`src/data/post-covers.ts` 集中配置封面，未配置时使用 MOEQY 品牌图，不需要改动文章正文。活动详情和介绍区的关于入口统一采用蓝绿色胶囊按钮。

文章标题恢复粉蓝渐变、网点和紧凑的标题／日期／分类排列。全站共用 `--gutter` 与 `--page-inset`，按扣除桌面侧栏后的可用宽度排版；容器最大 1440px，平板留白 32px、手机 20px。正文桌面 18px、手机 16px。

HarmonyOS Sans 分别加载本地 Regular 400、Medium 500、Bold 700、Black 900；英文展示字体为本地 LINE Seed JP ExtraBold 800，加载失败明确回退到 HarmonyOS Black。`redesign.css` 管理 v2 视觉规则、统一容器和手机菜单。

桌面保留右侧导航。手机菜单纳入页头布局，与 Logo 和语言入口垂直居中，随页头收紧移动；48px 点击区域保持不变，三横线约 0.3 秒变换为 X。打开时保留页头占位，确保语言入口和 X 的位置不跳动；同一按钮移动到原生 dialog 顶层，关闭后回到原位置并恢复焦点。按钮、Escape、遮罩和导航选择共用关闭流程，减少动态效果时立即关闭。

动画包括错落入场、滚动显现、连续文字带、角色旁的浮动符号、卡片悬停和弹窗过渡。保留原操作流程，并支持键盘标签切换、原生 dialog 的 Escape 关闭/焦点约束，以及系统「减少动态效果」设置。

## PICK UP / VISUAL CHANGE

首页准备三项 PICK UP，每次只显示一项。视频左下方 PICK UP 字样下方、与主字左对齐的三个缩略图可直接切换，桌面按本地参考站 `.kv-changer` 采用三个 150:80 圆角横图，横图在左，VISUAL CHANGE 和带圆形起点的紫灰细进度线在右；整组与 PICK UP 上下排列，选中项叠加 50% 紫灰遮罩；没有编号角标、选中边框、上移效果或标签底块。保留十秒进度和暂停／恢复按钮。视频背景不可点击；正文上方使用三张跨越分界线的叠层纸卡：PLAY MOVIE 播放影片、STORY & NOTES 打开当前项目的完整介绍、SELECTED WORKS 跳到 #works。影片卡封面和介绍入口随 PICK UP 更新；无视频时隐藏播放按钮并保留无交互、无焦点的空白纸卡。移动端空间足够时展示三张小卡；矮屏保留主字旁的影片卡，完整介绍与作品仍可从原有入口访问。窄空间切为上下排列，进度线与标签并列。支持方向键、Home／End；手动操作后重新计时。仅悬停文本信息区 `.pickup-info`、焦点进入、离开视口、页面隐藏或打开弹层时暂停，主动暂停后需要手动恢复；减少动态效果时默认停播并关闭切换动画。

编辑 `src/data/pickups.json` 可调整顺序、稳定 ID、封面及第二／三项的中英文标题、分类、状态、正文和链接。目前两项为可替换的演示文案：Concepts Game 筹备中、MyBlog 创作记录。第一项 `source: original-event` 由 `src/lib/pickups.ts` 复用原 `index.title`、`index.text`、2024.02.10 日期与原视频、详情链接，避免维护重复原文。演示作品使用筹备／内容分类，不伪造发布日期。

切换同步更新背景、文字、链接、完整介绍弹层和编号；离开视频项会暂停并卸载背景视频源，回到第一项才重新载入。视频弹窗仍按需创建并在关闭时卸载。无 JavaScript 时展示第一项，并提供全部三项的直达链接。`site.ts` 将控件底边对齐 PICK UP 下方的 MOEQY / FEATURED WORK 组合底边，允许控件跨越视频分界线；仅在矮横屏隐藏字样时保留独立紧凑位置，单屏高度及正文四行／手机两行限制不变。

## 作品维护

首页 WORKS 采用大图在左、介绍在右、底部 Logo 切换的展示方式，配合粉色网点与叠层纸张。桌面接近一屏，平板和手机上下排列。当前保留 Concepts Game、MyBlog 的封面、介绍、状态与访问地址。

编辑 `src/data/works.json` 即可维护作品；数组顺序就是轮播顺序。每项字段如下：

| 字段 | 用途 |
| --- | --- |
| `id` | 唯一、稳定的英文标识，仅使用小写字母、数字及分隔用连字符；不要随排序修改 |
| `enabled` | `true` 公开展示并生成详情页，`false` 隐藏且不生成详情页 |
| `homeFeatured` | 首页精选开关，缺失或 `false` 时不进入首页轮播 |
| `pageFeatured` | 作品页推荐开关，与首页独立；缺失或 `false` 时不进入推荐轮播 |
| `href` | 站内路径（例如 `/conceptsgame/`，英文页自动增加 `/en/`）或完整 HTTPS 地址；继续在新窗口打开 |
| `cover` | `public/` 下的横版封面路径，建议 16:9，例如 `/img/blog.jpg` |
| `logo` | 可选 Logo 路径；未提供时切换缩略图使用封面 |
| `text.zh-CN` | 必填中文文案：`title`、`category`、`description`、`cta`；可选 `subtitle` |
| `text.en` | 相同结构的英文文案；整项省略时回退到中文 |

将新图片放进 `public/`，复制一条记录并填写独立 ID、图片、链接和三语言文案，再创建 `src/content/works/{id}/zh-CN.md`、`en.md`、`ja.md`，然后运行开发预览或生产构建。两个精选开关分别控制首页和作品页，全部作品网格始终展示所有 enabled 项，保持数组顺序。现有文章 Markdown 与迁移快照不受作品数据修改影响。

轮播每 10 秒循环；Logo、左右箭头和方向键／Home／End 可手动切换。仅悬停当前作品文本区 `.works-copy`、键盘焦点停留、区块离屏或浏览器页面隐藏时暂停，恢复后重新计时。主动暂停后需主动播放；播放按钮获得焦点期间仍遵守焦点暂停条件。减少动态效果时默认不自动播放，动画关闭。只有一项时不显示控制区；没有启用作品时保留 `#works` 和空状态；禁用 JavaScript 时当前区域筛选后的作品按顺序展示，访问链接可用。

可视化编辑器留待后续制作，目标是统一管理作品与文章。本轮没有新增编辑器、管理服务或相关启动命令。
